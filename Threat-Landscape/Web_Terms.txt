Q:- What is user agent?
Ans:- A user agent is a software application, such as a web browser,
    that acts as an intermediary between a user and a network service like a website.
    It is responsible for making requests to servers, receiving responses, and rendering 
    content for the user.
    User agents identify themselves to servers through a user agent string, which includes
    information about the application, its version, and the operating system it is running on.
    This information helps servers tailor responses based on the capabilities of the user agent.

Q:- What is IP Rotation?
ANS: - IP Rotation is the general technique of changing your IP address at regular intervals or after each connection/request. 
       The goal is to make your online activity appear to originate from multiple different sources, rather than a single consistent IP address



Q:- What is Proxy Rotation?
Ans: - Proxy Rotation refers specifically to the process of using a pool of different proxy servers (and thus their associated IP addresses) 
       and automatically switching between them. When you use a rotating proxy service, you typically connect to a single entry point 
       (the proxy server's address), and that server intelligently routes your requests through different IP addresses from its vast pool.

Q:- Why are IP Rotation and Proxy Rotation Used? (Benefits)
Ans:- The main reasons for using IP rotation, especially via rotating proxies, are:

        Bypassing IP Bans and Rate Limits: Websites often block or throttle IP addresses that send too many requests in a short period
        (a common behavior of bots or scrapers). By rotating IPs, each request (or small batch of requests) appears to come from a 
        different user, making it much harder for websites to detect and block the activity. This is crucial for: 

            Web Scraping: Collecting large amounts of data from websites.
            SEO Monitoring: Checking search engine rankings from various locations.
            Price Comparison: Gathering pricing data from e-commerce sites


Q:- What is the Xpath?
ANS:- XPATH(XML Path Language) is a query language used for selecting nodes from an XML document. 
       It provides a way to navigate through elements and attributes in an XML document, allowing users to extract specific data or perform operations on the XML structure.
       XPATH is widely used in various applications, including web scraping, XML data manipulation, and testing frameworks like Selenium for locating elements in web pages.

       XPATH expressions can be used to select nodes based on their names, attributes, positions, and relationships with other nodes. 
       It supports various functions and operators for filtering and manipulating data within the XML document.


Alternatives to the XPATH:-

    CSS Selectors:-
                    CSS selectors are patterns used to select HTML elements to apply styles. 

    Regular Expressions:-
                    Regular expressions (regex) are sequences of characters that form a search pattern. 
                    They can be used to match and manipulate strings based on specific patterns.

    JsonPath:-
                    JSONPath is a query language for JSON (JavaScript Object Notation) data structures, similar to XPath for XML. 
                    It allows users to extract specific data from JSON documents using a concise syntax.

    DOM API Methods(JavaScript):-
                    The Document Object Model (DOM) API provides methods to traverse and manipulate HTML and XML documents in JavaScript. 
                    It allows developers to access elements, attributes, and content within the document structure.


    
Q:- What are the request headers???
Ans: - When a web browser (or any client application) sends an HTTP request to a server, it includes request headers. 
       These headers are key-value pairs that provide additional information about the request itself, the client making the request, 
       and the type of content the client prefers or can handle

       When a web browser (or any client application) sends an HTTP request to a server, it includes request headers. These headers are key-value pairs that provide additional information about the request itself, the client making the request, and the type of content the client prefers or can handle. They are crucial for the proper functioning of the web, allowing for efficient communication and content negotiation.



        Here are the different types of request headers, along with common examples and their uses:

        Categorization of HTTP Headers:

        HTTP headers are often broadly categorized into:

        General Headers: These apply to both request and response messages.
        Request Headers: Specific to requests, providing information about the client and the request.
        Entity Headers: These contain information about the message body (the actual data being sent, like a file or form data). They can appear in both requests (if there's a body) and responses.



Q:- What is the request parameters?
Ans:- These are pieces of data that are sent from the client ( e.g a web browser , a mobile app , a script).
      to the server as part of an HTTP request. They are essentially variables and their
      corresponding values that provide additional context or instructions for the server 
      to process the request.
